# LocalVibe

**LocalVibe** to aplikacja mobilna tworzona w technologii .NET MAUI.

## Funkcjonalności

- Strona główna
- Profil użytkownika
- Ustawienia aplikacji
- Obsługa kamery
- Przeglądanie aktualności
- Interfejs rejestracji użytkownika
- Spójny interfejs w niebieskiej kolorystyce

## Technologie

- C#
- .NET MAUI
- XAML
- .NET 10
- Visual Studio Code
- Xcode

## Uruchomienie projektu

Sklonuj repozytorium:

```bash
git clone https://github.com/p-majchrzak/LocalVibe.git
```

Przejdź do katalogu projektu:

```bash
cd LocalVibe
```

Przywróć zależności:

```bash
dotnet restore
```
